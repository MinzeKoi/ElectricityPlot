## 方法与固定范围

来源只涉及 House10/12/15/18，通道分别为 Appliance8/5/7/9；保留旧 C 两个半开训练区间及一小时间隔，日期和逐分区旧准入见 input_seal.json。House16 未登记微波炉，未将其缺标签当关闭。总表和标签覆盖率各至少90%，各至少7有效日、至少2个完整阈值片段的旧准入均通过。

8 秒时间加权、最多保持8秒；Issues=1 只使标签无效，缺失不视作关闭。中心总表及标签有效，partial 要求 core31 至少24点、无连续两点缺失；strict 要求 core31 全部有效，full127 要求127点全部有效。上下文不跨分区，外延在第二个连续缺失或边界停止。上游可能已填补或清零，4000W以上尖峰曾置零，无法恢复原始缺失。

window_ids.csv 的 grid_index 是所选28天规范化格点的零基行号，不是原始 CSV 行号。一个时间加权格点可由多个不同时间的原始观测贡献，本次不伪称存在一对一原始行号或提供未核实的行范围；原文件、切片及回执身份见 input_seal.json。逐日与片段支持、片段起止、排除原因分别见 daily.csv、fragments.csv。

## 独立复核和保护

主程序逐观测累积；独立程序使用每次保持最多跨两个格点的矢量化独立重算，逐格比较四户全部选定切片的总表与标签时间加权值和有限性。独立程序用前缀和重算每个分区 core31 与 full127，并逐条复核全部窗口 ID、标签、片段、停止原因，以及分区和 UTC 日总量。二者共用预先封存的输入身份、固定阈值和日期，但不共用数值计算函数；这不是独立数据来源。完整输出与测试见 independent.log、guard-tests.log。

数据加载前启用 Python 运行期精确路径白名单、禁止覆盖和进程内审计拦截，禁止未列文件读取、保留户路径探测、网络、进程启动和训练/模型模块导入。合成测试实际尝试禁止读/探测、网络、优化器/反传/模型模块及覆盖；测试也覆盖缺失中心、门槛、连续缺失、区间边界、延伸停止、Issues 和8秒保持。该保护是 Python 进程内控制，并非操作系统级沙箱；不声称能抵御恶意本地代码、原生扩展绕过或外部进程。
