# 固定门控分解：分析定义（计算前封存）

只读 Task24/25 三种子已选来源 `source_results/scores_{seed}_{4,5}.npz` 及各自 `source_selection.json`、`source_complete.json`；逐文件验证来源完成清单身份与选择结果绑定。逐 seed/block 对齐两候选及所有种子的完整 t、ix、y；仅在共同 ix 上以原模型保存的 p、h 和原固定 L、H 得到 A=(p>=L)、B=(h>=H)。四象限分别按 y=0/1 计数，正式门控 A∧B 的混淆必须复现原 selection 每块记录；A 单独及 B 单独仅用于解释，不构成候选、评价选择或新阈值。

同一 seed/block 的负例，给每点定义旧状态 AB 和新状态 AB，统计 4×4 迁移表。新增 FP 为旧非11到新11，按旧状态 00/01/10 穷尽互斥分组；去除 FP 为旧11到新非11，按新状态 00/01/10 穷尽互斥分组。00 表示两个条件都未通过，01 仅峰值条件通过，10 仅点分数条件通过。两条件及模型同时改变，只是状态分解，不能归因单一条件的因果贡献。

每块报告支持和正例数；报告 L-only 下被 H 保留/滤掉的 TP 与 FP。均为点数，不代表事件数。数据有限标签，且本项问题不需峰位置或误报距离，因此不计算峰位置、开机距离或物理原因。不得重训、推理、变更/搜索阈值或半径、选择模型或读取 House17/最终 8/9/20。此诊断限固定来源重复使用，非独立泛化验证。
