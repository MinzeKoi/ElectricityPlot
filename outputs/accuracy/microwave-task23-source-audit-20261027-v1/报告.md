# Task23：四户微波炉来源可行性审计

## 结论

四户、八个原 C 来源训练分区均符合旧微波炉准入条件，并在当前窗口规则下保留了真实开机中心。工程上具备提出后续受控多户 TCN 对照的来源基础；仅凭这些数据无法证明性能收益。House12、15 的完整片段数量很少，特别是各自第一分区仅 3、2 个，独立物理使用次数可能更少。

旧 data-expansion-20261024-v1 已实际进行多户扩数，采用独立设备功率回归、开机权重50、来源 normalized MAE 选择 checkpoint，结果为负；该结果不能直接等同本次分类器问题。Task22 容量对照的来源事件门控未通过，不能证明容量足够或多户必然有效。

## 固定来源与方法

仅访问 House10、12、15、18 的获准原始文件、回执、切片与来源专用规范化文件；通道和路径与清单、catalog、切片回执核对。每户沿用旧 C 两个半开来源训练区间，中间排除一小时；精确 UTC 日期及旧逐分区准入记录见 input_seal.json，逐分区计数见 partitions.csv。House16 无登记微波炉，不视为关闭。旧准入为总表及标签各至少90%覆盖、各至少7个有效日、至少2个两侧有观测关闭值的完整阈值片段；八段均通过。

逐切片以独立时间加权方式重算全部 8 秒格：每条观测最多保持8秒，覆盖不足8秒为缺失；Issues=1 时标签无效，总表不受该标志过滤。与两个规范化输入的有限性及数值逐格一致。200W 为固定标签阈值；未知标签不算关闭。上游已前向填补、清零，且超过4000W的 IAM 尖峰被上游置零，这些原始信息无法恢复。

partial 要求中心总表和标签有效，core31 至少24格有观测且无连续两格缺失；strict 要求 core31 全部有观测；full127 要求127格全部有观测且不跨区间。上下文外延在边界或第二个连续缺失处停止。八个分区边界无活动片段截断。片段仅为可观察的连续阈值片段，不等于独立物理 cycle。

daily.csv 按 UTC 日和原分区列出格点、有效标签/总表、开关中心和互斥排除原因；片段数按起始 UTC 日计，跨日片段不重复。fragments.csv 给出各片段时间、完整性和三种支持下的保留中心；window_ids.csv 只含合法 partial 中心及视图标识、停止原因和片段映射，不含训练 x/y 功率包。raw_index 为所选28天规范化格点零基行号，不是原始 CSV 行号。

## 复核与局限

独立检查核对 1,057,163 个窗口 ID 的唯一性、视图/日/片段分组计数，并逐点抽查 1,161 个窗口的时间、标签、core31、full127 和两侧停止原因；四项合成测试覆盖时间加权、Issues、长缺口及重复时间戳。全部八个分区的旧有效数、活动数、完整片段数均复现。完整日志见 tests.log。

输入白名单、日期、通道和主审计源码在计算活动支持前封存，原始、切片、规范化、配置及代码身份见 input_seal.json；交付和输入的最终身份见 delivery_seal.json。独立核对源码是在主计算之后编写并封存的。审计程序以明确路径读取指定数据且无训练、推理、下载调用，但本次没有操作系统级禁读、网络、优化器或反传拦截器；因此不能把代码检查提升为运行期隔离证明。

本轮未新增训练池、归一化、候选推理、拟合或模型搜索。实际数据合并、采样/步数及模型预算需另行准备并获得新授权。
