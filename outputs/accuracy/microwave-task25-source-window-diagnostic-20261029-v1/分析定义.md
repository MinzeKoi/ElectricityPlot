# 来源窗口描述：固定分析定义（计算前）

仅使用 Task24 注册的 House5 source validation block4/5 原 C127 窗口、mask、y/t/house，及 Task24/25 封存所选来源分数、固定 L/H；核对注册路径与摘要、分数完成清单、完整 t/ix/y、一致的窗口 t 与二值 y、house/block 和正式混淆。固定支持、各 seed/block 分开；按共同 FP、仅24 FP、仅25 FP、共同 TN、共同 TP 五组；任何未列组合不参与这五组，各组分母、支持、缺失量均明确。点与窗口重叠，不把组和种子合并当独立样本。

统计 mask 的 core31（索引48:79）全观测比例、full127 全观测比例、outer96 有效格数。窗口 x 存的是原始总表功率，代码 `expand_context` 直接赋值，`tensor_input` 才做 log1p 标准化；不对它反归一化。按已观测且有限的格子计算中心值、core31 与 full127 内 max-min，及每视图相邻位置双方均有限的绝对变化最大值，绝不跨缺口；若无有效值或有效相邻对则记缺失。分布用 numpy 线性插值 P10/P50/P90，单列非缺失数和缺失数，不做显著性筛选或事后选择图。原标签 y 仅统计数值有限且非负者 0、(0,200)、>=200 三类；负值/非有限为 unknown，不计为 off，给数量与组分母。200 是已有状态阈值。

不计算事件/开机距离，不推断设备、训练、推理、阈值或特征选择；不访问开发或最终数据。结果只描述重复使用的固定来源，不能证明原因或跨户泛化。
