# M5 冻结实验交接

日期：2026-10-20。M5 工程实现完成；正式多户盲测和独立成员验收尚未完成。现有 REFIT House 3 前缀测试成绩已在 M2/M4 查看过，本次不得重新标记为首次最终评价，也不得据结果调参后继续使用同一测试集宣称盲测。

## 实验定义

入口为 `scripts/run_m5.py`，配置为 `configs/m5_experiment.json`，实现位于 `src/virtual_submeter/experiments/`。依赖复用 Python 3.12 CPU 环境及 `requirements-m4-cpu.lock`，没有新增第三方依赖。

| 组 | 实际执行 | 主报告视图 |
|---|---|---|
| B0 | 来源协议下的全零基线 | 原始功率、原始状态 |
| B1 | 每个种子独立来源训练、不做目标适配 | 原始功率、原始状态 |
| B2 | 相同主干、相同预算、随机选片和 MIL 状态适配 | 原始功率、适配状态 |
| B3 | 相同主干、相同预算、仅不确定性选片 | 原始功率、适配状态 |
| P1 | 相同主干、相同预算、不确定性/影响/可回答性组合选片 | 原始功率、适配状态 |
| P2 | 直接复用 P1 的模型、回答和预测；来源经验区间及向下修正 | 修正功率、适配状态 |

B3 是同时移除影响与可回答性因素的对照，不能单独解释两个因素各自贡献。P1/P2 是可信输出处理的成对消融。所有主干始终冻结功率，状态提升不能解释成功率提升。各次评价仍保存 raw/corrected 全套指标；P2 不额外训练、不额外花费预算。

预算 0/5/10/20，种子 42/1019/2026；每个种子均重新训练来源 CNN。B0/B1 每户每种子各执行一次零预算，B2/B3/P1 对所有预算执行。P2 是 P1 的配对视图，不伪造额外独立样本。一户完整矩阵有 42 个实际预测、54 个组/预算/种子结果；三户为 126 个预测、162 个逻辑结果。每设备分别汇总。

## 冻结和评价边界

1. 检查四类划分、整户隔离、时间隔离、种子和预算。`final` 模式要求正式协议、至少三个目标家庭和三个种子、完整协议预算、CNN 与背景压力实验，以及未评价测试集的明确声明。合成/前缀协议和已查看测试不得进入该模式。
2. 保存完整配置、协议、Python 包源码、依赖锁及实际环境。训练每个种子的 B0/B1，仅用来源验证校准；完成所有家庭、策略、预算的查询和状态适配。
3. 保存全部常规测试预测，生成 `freeze.json` 及全文件 SHA-256 清单。此前禁止读取任何目标测试分表。查询代理只给已选窗口的模拟弱回答。
4. `evaluate` 校验全部冻结文件、协议和当前源码。打开测试标签，保存全部指标；随后按已冻结参数执行 P1/P2 背景压力对照，每个背景实验还会先保存两份预测再读取标签。评价阶段没有拟合、选片、校准或超参数选择。
5. 导出 `summary.json`、`summary.csv`、`report.html` 和 `evidence.json`。只读 `verify` 校验文件身份并重新从逐次指标构建汇总，禁止重开分表答案。

测试历史是操作者声明，文件哈希不能证明某人从未看过数据。正式模式通过也不自动证明独立复现或算法优势，因此 `formal_acceptance` 始终为 false，须由团队另行审阅并提供独立证据。原始负结果、未定义指标和质量不足不应隐藏。

失败时保留 `run.json` 中的错误和阶段，缺少完整证据不能显示成功；已有目录不覆盖。评价使用独占锁，禁止并发重复评价；已评价或评价失败的运行禁止再次执行评价。修复后需新建运行并如实更新测试已查看声明，不能借此重置测试历史。

## 命令

真实前缀工程验证，直接运行完整矩阵：

```powershell
python scripts/run_m5.py run --manifest data/processed/refit_m4_protocol/protocol.json --output outputs/my-m5
python scripts/run_m5.py verify --run outputs/my-m5
```

先审阅冻结证据、后评价：

```powershell
python scripts/run_m5.py freeze --manifest data/processed/refit_m4_protocol/protocol.json --output outputs/my-m5-frozen
python scripts/run_m5.py verify --run outputs/my-m5-frozen
python scripts/run_m5.py evaluate --run outputs/my-m5-frozen
```

跨机器评价可传 `evaluate --manifest 新路径/protocol.json`，协议字节和所有数据哈希必须一致，源码指纹必须与冻结时一致。`frozen/source/` 保存了包源码用于恢复；复跑应使用相同依赖锁和完整项目版本。适配会话保留原机器绝对路径供原机交互恢复，但 M5 只读产物复核不依赖这些路径，也不需要原始分表。

第二成员在其机器使用相同配置和数据重新执行 `run`，再比较：

```powershell
python scripts/run_m5.py compare --left outputs/member-a --right outputs/member-b
```

比较设置、协议、源码、完整预测行、语义查询记录、指标、汇总及背景影响；排除运行时间、模型生成时间等非数值结果身份。默认绝对/相对容差均为 `1e-9`；差异返回非零退出码。同一个目录不能与自身比较。数值一致性不证明操作人员或机器独立，第二成员应另外记录姓名代号、机器与执行说明。

无真实文件时，生成五户来源/目标隔离的合成数据，覆盖三个目标家庭、全部种子/预算：

```powershell
python scripts/run_m5_synthetic.py --output outputs/my-m5-synthetic
python scripts/run_m5.py verify --run outputs/my-m5-synthetic/run
python -m unittest discover -s tests -v
```

Windows 沙箱中先把 `TEMP`/`TMP` 设置为已存在的项目内 `tmp` 路径。所有目录须为新目录。

## 报告解释

先在每户内平均各随机种子，再对家庭等权平均，避免较长家庭或更多有效点支配结果。保留逐户种子样本标准差、家庭间样本标准差、有效数和缺失数；单个有效值的标准差为空，不用零代替。种子不是独立家庭，不输出基于伪独立样本的显著性结论。

逐设备报告全时段/运行段 MAE、Precision/Recall/F1、周期电量绝对误差和有效覆盖；完整逐次报告还包含 UTC 日电量、超限与修正、归因比例/归因误差、区间覆盖和宽度。P1 与 B1/B2/B3 保存同家庭、同种子的配对差值；功率误差越低越好、F1 越高越好，不自动挑选“最佳预算”。

训练成本按种子单列，不对每次适配重复收费；每次适配/推理耗时和确认响应分布单列。记录机器 CPU/内存容量，但未测量峰值进程内存。合成压力保留有/无背景分组、误激活、漏归因及全未解释对照。所有模拟回答标记为 `simulated_from_submeter`。
