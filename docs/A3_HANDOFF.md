# A3：动态选片与确认反馈循环

负责人：本次实现会话。开始日期：2026-10-21。

输入为 A2 选出的 `L2_max`、三个来源种子的冻结 CNN、来源状态头、回放及来源标准化；训练参数复用 A2。新增配置仅定义查询策略，不调整学习器或来源模型。主输出位于新的 `outputs/accuracy/a3-20261021-v3/`，旧实验产物不覆盖。

## 实现与固定规则

| 策略 | 行为 |
|---|---|
| random | 从完整未询问候选池确定性随机抽取 |
| uncertainty | 按当前 L2 状态输出的窗口最大分数计算不确定性 |
| proposed | 不确定性、总表形态多样性、设备覆盖及固定比例随机探索 |
| uncertainty_static | 零确认状态评分固定，保留相同适配频率 |
| proposed_static | 零确认状态评分固定；多样性和覆盖仍依据已询问记录更新 |
| proposed_no_diversity | 移除多样性项，其他权重保持冻结值 |
| proposed_no_coverage | 移除设备覆盖项，其他权重保持冻结值 |

每 5 次回答从来源参数重新适配，使用截至该时刻全部已回答窗口；不继承上轮目标参数。0/5/10/20 是同一条 20 次轨迹的前缀，同时保存第 15 次后的轮次模型。三设备共享总预算，不确定与跳过均计费。每个来源种子独立运行轨迹；所有策略使用同一候选完整性、训练频率、来源回放量和参数约束。

候选沿用 M3 的总表完整性和不重叠网格，只依据总表及预测支持生成。状态窗口分数为当前状态分数的最大值，不确定性为 `1 - 2 * abs(score - 0.5)`。形态使用窗口总表的均值、标准差、极差和平均绝对差分的 log1p，按完整适配池做无标签标准化；与已询问窗口的最近形态距离转换到 [0,1)。覆盖项为 `1 / (1 + 该设备已询问次数)`。完整策略权重为 0.5/0.3/0.2，每次提问有 10% 固定种子探索机会。未知窗口的正负标签不参与评分与设备平衡。

版本 2 会话保存候选池、查询配置、协议和基础模型哈希，以及每轮可见前缀、模型、状态窗口评分和哈希。pending 在代理读取前持久化；重复请求幂等，重复回答拒绝。读取时按每个问题当时的模型重放策略。M3 版本 1 会话仍由原模块读取。`resume` 支持初始输入准备完成后，冻结查询阶段的中断；要求同一路径、相同源码和输入，恢复后重新计算各预算模型以核对确定性。

功率、电量及未解释部分保持原值；状态分数未经校准。完整查询／模型／未来预测矩阵冻结后才读取开发未来标签，评价后禁止重新进入冻结或再次打开标签评价。核验只读取已封存指标和产物，保留每户、每设备、每来源／查询种子的负结果。

## 历史输入完整性

受限沙箱无法枚举本机 A2 的 42 个已发布派生缓存／会话文件，直接访问会返回拒绝访问，不能据此断言文件已删除。2026-10-21 已在正常本地访问权限下完整核验 A2，252 案例、756 行指标及原封存清单全部通过。A3 主运行采用同样权限，来源收据为 `a2_full_evidence_verified`。

A3 另支持明确标记的受限视图路径：独立核对所有可访问字节、模型、查询前缀、来源头、回放、时序特征和评价证据；缺失核心证据或任意保留文件哈希变化均拒绝。仅允许原清单中的派生预测缓存与轨迹会话不可见；嵌套随机前缀由封存模型的 `queries.json` 交叉核对。收据必须标记该视图不能完整核验历史 A2，不将其等同于完整验证。

A3 在自己的目录用原 CNN 和总表重新生成预测；来源状态头与时序特征逐字节复用。来源收据位于 `frozen/inputs/parent_receipt.json`。最初受限视图试运行 `outputs/accuracy/a3-20261021/` 与修正通用 CSV 导出前的 `a3-20261021-v2/` 均在评价前停止，状态为 `interrupted_before_evaluation`，不计作完整结果。

## 开发结果与后续决定

主设备为水壶与微波炉，洗衣机作为扩展保留。下表主预算固定为每户 10 次；先平均来源／查询种子，再设备等权；当前仅一个已查看 House 3。

| 策略／消融 | 主设备 F1 | 相对自身零确认 | 相对随机 |
|---|---:|---:|---:|
| random | 0.1778 | +0.0021 | 0 |
| uncertainty | 0.1854 | +0.0097 | +0.0076 |
| proposed | 0.1810 | +0.0053 | +0.0032 |
| uncertainty_static | 0.1905 | +0.0149 | +0.0128 |
| proposed_static | 0.1808 | +0.0052 | +0.0031 |
| proposed_no_diversity | 0.1879 | +0.0123 | +0.0102 |
| proposed_no_coverage | 0.1892 | +0.0136 | +0.0115 |

共同零确认 F1 为 0.1757。完整拟议策略相对随机平均提高 0.003228，即约 **0.32 个百分点**；三查询种子的配对收益为 +0.005108、+0.004882、−0.000306。最低开发出口通过，预先冻结的 +0.02 内部目标未达到。全部案例未出现由确认新增的全关／全开；主预算主设备平均损失未超出冻结容差。功率、电量与共同有效支持保持一致。

拟议策略的 5／10／20 次相对随机收益分别为 +0.01146／+0.00323／+0.000033，收益未随预算增加而稳定提高。主预算仍为 10 次；其他预算作为完整成本轨迹保留。静态不确定性优于动态不确定性，移除多样性或覆盖也优于完整策略；本轮证据不支持宣称动态刷新、多样性或设备覆盖产生优势。

主预算九条种子轨迹合计 90 次模拟回答：拟议为 0 正／37 负／53 不确定，随机为 0 正／51 负／39 不确定。主预算下所有策略均未取得水壶正回答。这些计数来自同一个家庭的重复种子实验；缺失支持造成的不确定回答计费，选片依据仍仅限总表和当前可见信息。

后续保留随机和简单静态不确定性作为参照，优先扩展完整事件和开发家庭、处理来源表示及误报，再冻结有限候选。状态证据仍较弱，A4 功率联动后置；A5 须使用新家庭和统一盲测屏障。只有一个已查看开发家庭，来源／查询种子不代表独立家庭；最终多户 H1/H2/H3、噪声敏感性、真实用户确认、功率收益和独立人员／第二台机器复跑仍待完成。
