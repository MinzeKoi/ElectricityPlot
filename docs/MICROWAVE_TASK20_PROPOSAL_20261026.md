# Task20 提案：来源误报与真实开机的输入相似性诊断

## 问题与依据

Task19 已封存于 outputs/accuracy/microwave-fit-generalization-diagnostic-task19-20261026-v4。旧模型在 House2/19 未训练日期上 Recall 下降且 FPR 上升；扩展模型改善新增日期拟合，但 House5 后缀固定点 F1 从 0.381312 降至 0.365947。完整训练分布也未接近完美分类。这些证据尚不能区分优化、模型表达、输入歧义和标签问题。

本轮只回答：冻结模型误报的来源窗口，与真实微波炉开机窗口的已观测输入有多相似？相似性是否在跨日期时变化？增加到既有127点上下文，是否能分开在31点内相似的正负窗口？相似不等于不可辨识；本轮不声称证明信息论上的不可分，也不以距离改模型输出。

## 固定分析

1. 校验 Task19 完整矩阵、阈值、身份映射和 manifest。逐 house/role/UTC日期/seed/family 汇总既有 FP、FN、TP、TN 支持；窗口和可观察片段不能当作独立物理事件。
2. 对核心31点完整的原窗口检查模型有效输入的精确重复：相同输入但中心开关标签不同的组、窗口数、跨日期情况和缺失掩码分布。哈希仅作为索引，命中后逐元素确认；必须包含模型实际输入的掩码及全部127点通道，不能用仅31点重复宣称完整模型输入冲突。
3. 在同户范围做预定义相似窗口配对。使用原冻结转换后的功率尺度，不重估缩放、不去除窗口均值、不优化距离。31点距离用逐点 RMS；127点距离只在全部127点完整的共同子集中比较，同时报告该子集覆盖率。31与127比较必须使用相同查询与参考窗口。
4. 参考库仅来自相应模型实际训练角色：control 用原训练前缀；expanded 用完整训练角色。每 household、训练角色、标签分层，用稳定窗口ID的 SHA256 升序固定保留至多256个开机窗和4096个关闭窗，报告保留量与原支持，不按模型得分挑参考。
5. 查询按 family/seed/house/role/UTC日期及 FP/FN/TP/TN 分层，稳定ID哈希升序各至多32窗；标签/错误类别只用于描述分层。查询与参考同日禁止配对；相距不足127×8秒也禁止配对，避免重叠窗口近邻。无合格参考时记录缺失，不跨户补齐。
6. 对每个查询保存最近正参考和最近负参考及距离、距离比、时间间隔、原标签功率、预测概率、掩码和身份。给出完整预定义分组分布；不把距离比当新分类器，不选判别阈值，不据此计算新模型验收成绩。
7. 展示哈希顺序固定的少量 FP/TP、FN/TN 配对曲线，明确“参考库内最近”和抽样限制。连续聚集窗口按原事件/关闭片段去重展示；原计数不去重改口径。模型错分但输入不接近，只支持继续检查训练/表达；输入接近且标签冲突，只是待复核线索，不能直接宣布标签错误或物理不可分。
