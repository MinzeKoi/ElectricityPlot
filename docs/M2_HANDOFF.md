# ElectricityPlot · M2 交接记录

日期：2026-10-20（北京时间）。本次完成 M2 工程闭环：来源训练→验证选模型→未见家庭总表预测→独立评价→曲线和报告。沿用 M1 的单目标家庭工程协议，不补写为正式三户实验。

## 实现范围

- 单水壶和三设备轻量序列到点 CNN；来源训练均值与零预测作为 B0 对照，未适配 CNN 作为当前 B1。此 CNN 是项目的小型实现，不宣称复现原论文完整结构或成绩。
- 来源家庭标签训练，来源验证集归一化 MAE 选 checkpoint；所有设备阈值和超参数在读取目标测试成绩前确定。没有目标家庭标签适配，没有用户确认。
- 版本化模型、weights-only 权重重载和 SHA-256 核验；配置、源码指纹、环境、训练历史、耗时、种子及零查询记录可追溯。
- 总表独立预测，保存原始/修正功率、状态、未解释部分和质量标记；可信度恒为 null。缺失和上下文不足不算设备关闭。
- 独立评价输出逐设备 MAE、运行片段 MAE、Precision/Recall/F1、共同有效区间电量误差、按 UTC 日积分和覆盖率。修正前后指标均保存。
- Streamlit 单机界面支持已有真实家庭记录、用户 CSV 导入、历史回放、评价与 HTML/CSV 下载。错误或输入/模型变化会清除旧结果。

## 配置与边界

沿用 `data/processed/refit_m1_protocol/protocol.json`：House 2 来源训练、House 5 来源验证、House 3 适配池/冻结测试，适配池与测试隔离 3600 秒。模型训练和选择均没有读取 House 3 分表。当前只是 `engineering_pilot_only`；清洗版上游补值未知、前缀较短、单户及单种子等局限保持不变。

`configs/m2_baseline.json` 固定：31 点 / 248 秒窗口、两层 8 通道卷积、32 单元隐藏层、8 epochs、batch 256、Adam 学习率 0.001、运行点损失权重 5、seed 42、CPU 4 线程。三设备模型 8,315 参数，单设备 8,249 参数。此离线模型使用未来上下文，不称为实时识别。

归一化与功率缩放只使用来源训练窗口，逐户生成窗口，不跨缺失、时间跳变或划分。训练可用中心窗口为 23,334 个，来源验证为 18,527 个。水壶模型选第 2 epoch，三设备模型选第 8 epoch，选择依据均为来源验证集，而非 House 3 成绩。

预先固定的状态阈值为水壶 2000 W、微波炉 200 W、洗衣机 20 W。状态由对应功率是否达到阈值定义，不把任意网络值命名为可靠概率；未来要修改阈值，应在来源训练/验证上完成，再对新的正式测试协议评价。

冻结测试为 UTC `[2013-09-27 03:21:52, 2013-09-28 09:22:40)`，共 13,506 个 8 秒区间。各基线都有 12,068 个有效预测（89.35%）；再与有效分表取交集后，指标使用 10,713 个区间（79.32%）。以下为一致性修正后的实际结果，单位和评价支持一致。

| 来源均值 | 洗衣机 | 26.07 | 270.95 | 0 | 0.0718 |

当前 CNN 的运行片段误差和状态 F1 与简单对照不同，但其全时段 MAE 和电量误差较差，表明误报仍明显。不能只挑 F1 或运行片段指标宣称总体优越；零预测的低全时段 MAE 也不证明其能识别电器。这些是初始负结果，不是最终正式成绩。电量误差只对应共同有效区间，不是完整日账单误差。

三设备 CNN 修正前超限率为 0.4475%，平均去除功率约 1.3653 W；有效预测区间可归因电量比例约 38.46%。未解释积分含建模与测量误差，不能将它称为真实未知设备耗电。这些一致性统计不替代 M4 的可信输出实验。

原始精度、状态计数、按日支持和指标数字见 `docs/M2_RESULTS.json` 与各运行的 `metrics.json`，不手工回填虚构成绩。三设备首次训练总耗时约 5.31 秒，含拟合约 4.15 秒；该次推理含模型加载约 1.77 秒。不同机器/首次导入时间会不同。

## 环境与复跑

独立环境 `.venv-m2`：CPython 3.13.5 / Windows AMD64、NumPy 2.3.4、PyTorch 2.9.0+cpu、Streamlit 1.50.0。完整传递依赖锁为 `requirements-m2-cpu.lock`，CPU 版本依据 [PyTorch 官方安装说明](https://pytorch.org/get-started/previous-versions/)。不依赖显卡，不改全局 Python；其他平台和第二名成员的机器未验证。

README 提供安装和逐阶段命令。完整复跑可执行：

```powershell
.\.venv-m2\Scripts\python.exe scripts/run_m2.py --output outputs/my-m2
.\.venv-m2\Scripts\python.exe scripts/verify_m2.py --run outputs/my-m2 --manifest data/processed/refit_m1_protocol/protocol.json
```

四个模型全部训练完成后，批量入口才进行测试评价。既有运行不覆盖；失败运行记录 failed，不把部分成功当成完整结果。相同配置的本机第二次运行保存在 `outputs/m2-20261020-reproduction/`，用于核对可复现性。这不是第二位成员或第二台机器的独立复现，也没有按第一次测试成绩调整参数。

本次验收：46 项测试通过，涵盖 M1 兼容、数值指标、真实训练/重载、来源标签访问、同种子复现，以及 Streamlit 分析/评价和失效后清除旧结果。四个基线各 13,506 行预测及全部指标在第二次运行中完全一致，证据为 `outputs/m2-20261020/reproduction.json`。源码编译、依赖一致性、M2 产物复核和 ElectricityPlot 0.3.0 wheel 构建均通过。本地界面健康检查返回 ok；不以这些工程检查替代算法效果。

## 产物与启动

- `outputs/m2-20261020/{single_kettle,seq2point,constant_mean,zero}/`：模型、环境、参数、训练历史和配置。
- `outputs/m2-20261020/predictions_<基线>/`：真实预测 JSON、CSV、运行说明和无真值分析报告。
- `outputs/m2-20261020/evaluation_<基线>/`：包含真实指标的 `metrics.json` 与独立 `report.html`。
- `outputs/m2-20261020/{run.json,summary.json,verification.json}`：首次运行追溯与复核。
- `docs/M2_RESULTS.json`：可入 Git 的小型结果证据摘要，不包含原始总表或分表序列。

启动界面：

```powershell
.\.venv-m2\Scripts\python.exe -m streamlit run scripts/app.py
```

仅监听 `127.0.0.1:8501`。默认加载已生成的三设备模型；更换模型或协议可展开高级设置。用户 CSV 必须先明确 W 单位、家庭标识及带时区时间；界面会调用同一导入/预测接口，不在页面回调中训练模型。模型缺失、输入不合格或分析失败时不展示默认曲线或旧结果。
