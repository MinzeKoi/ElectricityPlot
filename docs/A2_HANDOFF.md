# A2：固定确认集合的学习器比较

负责人：本次实现会话。开始日期：2026-10-21。

输入为 A1 冻结的三个来源种子权重及其独立开发协议。输出为新的 `outputs/accuracy/<run_id>/`，包含固定随机查询轨迹、来源时序特征缓存、来源状态头、各预算模型、紧凑状态预测、配对指标、消融和证据清单。原有 A0/A1/M1–M5 产物保持不变。

验收要求：相同家庭、查询种子和预算下，所有学习器使用完全相同的确认前缀；每个来源种子复用对应 A1 权重；每个预算从来源初始化训练；分别比较各学习器自身零确认基线；无有效回答严格不更新；来源回放只使用来源逐点标签；目标正回答只监督至少一次使用。全部模型与未来预测冻结后，才打开开发未来分表。工程完成和真实确认收益分别验收，不启动 A3。

接口见 [DATA_CONTRACT.md](DATA_CONTRACT.md)，冻结配置见 [a2_learners.json](../configs/a2_learners.json)。

## 已实现的比较

| 名称 | 状态学习与保护 |
|---|---|
| L0 | 原 M3 三系数最大池化 MIL，保留退化参照 |
| L1 | 原始功率阈值的有界 logit 偏置校准，不改变斜率 |
| L2_max_unprotected | 来源训练时序状态头，目标最大池化，无保护 |
| L2_max_bound | 加参数范数限幅及单类保守偏置规则 |
| L2_max_replay | 在上一项上加固定来源回放 |
| L2_max | 再加向来源参数的 L2 正则 |
| L2_smooth | 完整保护，正窗口改为平滑 log-mean-exp；负窗口仍约束最大活动 |

L2 使用冻结 CNN 的 32 维倒数第二层表示，加偏置及原始功率阈值对数比，共每设备 34 个参数。特征均值／方差只由来源训练计算。来源状态头最多训练 80 轮，每 5 轮在来源验证逐点 F1 上选择；每设备最多均匀采样 20,000 个来源训练点，正类损失权重上限 20。每来源种子只训练一次，全部目标预算和 L2 消融共用。

目标更新固定 200 步，学习率 0.05，每预算从同一来源参数初始化。L1 混合回答偏置绝对变化至多 log(2)；单类回答的受保护更新仅改变偏置，幅度至多 0.25。L2 混合回答参数变化 L2 范数至多 0.5。来源回放每设备最多 512 点、两类等量采样，跨预算和消融复用同一固定缓存；权重 0.2，来源正则系数 0.1。平滑正窗口温度 0.25。这些值在本次开发未来评价前写入配置，没有根据未来评价早停或回退。

默认固定随机轨迹使用三设备完整候选池；相同查询种子的一条轨迹跨三个来源种子复用。洗衣机占用的确认照常计入每户总预算，不能移除后仍称同一次实验。主设备为水壶／微波炉，洗衣机为扩展，其失败仍完整保存。

`frozen/cases/seed_42/house_3/query_42/L2_max/budget_10/model` 等目录是可独立加载的功率冻结模型，通用 `scripts/project.py predict` 可直接调用。`states.npz` 与同种子的 `frozen/cache/.../predictions.json` 共同恢复完整预测；按文件清单核验二者身份，不重复储存各案例相同的功率曲线。

新增 8 项测试覆盖 MIL 聚合梯度、正窗口语义、无标签严格恒等、单类限幅、缺失支持、来源标签隔离、全矩阵冻结屏障、共享前缀、通用模型重载与预测、重复评价拒绝和损坏产物拒绝。完整 111 项测试通过（65.863 秒）；工程检查不代表真实确认收益成立。

真实全矩阵另做只读边界复核：252 个案例的功率权重均与对应 A1 种子完全一致；252 个无有效回答的设备案例参数严格等于自身来源参数；360 个受保护更新满足限幅，其中 270 个单类回答更新保持全部斜率不变。真实 seed 1019 的 L2 模型重载后，21,150 个未来总表时间点的分数与冻结缓存逐点一致（绝对容差 1e-12，含相同缺失位置）；此复核未读取目标逐点分表。

## 确认分布、局限与下一步

三条最长 20 次固定随机轨迹都没有水壶 `used` 回答。主预算 10 次的回答分别为：query seed 42 为 0 正／6 负／4 不确定，seed 1019 为 0／6／4，seed 2026 为 2／6／2；后者只有微波炉和洗衣机各一个正回答。没有依据未查询答案重抽、补齐正例或删去不确定回答。这解释了大部分受保护更新为何落到单类保守偏置规则，也意味着尚未充分验证水壶正窗口学习。

当前只支持“保护措施在这个固定随机开发集合中控制退化并产生小幅平均收益”。继续巩固 A2 时，应优先扩大可用开发记录与完整事件支持，检查随机确认正例稀缺及微波炉误报，保留同预算公平比较；不通过人工挑正样本来制造收益。本次未实现 A3 动态查询，没有多户盲测、真实用户确认、独立人员／第二台机器复跑或功率收益。

本机冻结及独立核验需要与原 A1 权重相同的文件访问权限；普通受限沙箱无法枚举其中 42 个经临时目录发布的文件，会报告清单不完整。在相同获准权限下，全部 1,668 个冻结文件均校验通过，没有产物内容变化。详见验证摘要中的 `local_access_note`。
