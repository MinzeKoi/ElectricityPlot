# F1 偏低的原因与改进方向：综合结论（2026-10-29）

## 结论和状态

本轮分析及已授权的对照和来源诊断已完成。现有证据表明，历史微波炉低 F1 的直接问题是大量关闭点被判为开机；低开机基率会进一步压低 Precision。若干固定配方下的增宽、扩户及正例份额调整未通过来源资格，**尚无证据替换 `control_guard95` 或证明总体 F1 提高**。下一步优先建立未用于选择的独立来源评价，而不是自动继续试训练比例。

主目标是水壶与微波炉等权平均 F1，洗衣机为扩展设备。历史开发 A 组水壶 F1 0.7555、微波炉 0.0769、主设备平均 0.4162；微波炉是这一结果的主要短板。后续 Task22、24、25 是微波炉状态分类的固定来源对照，没有新增开发 F1，也不能由此推断水壶、功率或电量改善。[历史诊断](F1_DIAGNOSIS_20261024.md)

## 已知：误报和低基率是低 F1 的直接表现

历史 House17 开发 A 组微波炉 Precision 0.0401、Recall 0.9243；每种子平均约 TP 354、FP 8,482、FN 29。真实开机占比仅 0.278%，来源验证为 1.345%；两者关闭点误报率约 6.18% 和 5.98%。因此在使用较少的家庭中，即使关闭点误报率相近，也会有大量误报相对少量真阳性，导致 Precision 和 F1 很低。这是已查看开发区间的描述，不代表所有家庭。[历史诊断](F1_DIAGNOSIS_20261024.md)、[目标交接](F1_GOAL_HANDOFF_20261027.md)

历史冻结功率输出中，来源选择单一阈值后开发 F1 由 0.0769 到 0.0857；利用开发答案事后选单一阈值的诊断上界也只有 0.1279。后者不能用于选型或声明泛化，但说明这些冻结分数的正负排序有明显重叠。在有完整标签邻域的开发误报子集中，约 97% 距真实开机超过 248 秒，说明大量错误并非仅为已标记事件边界拖尾。此统计只适用于其可判别子集。[历史诊断](F1_DIAGNOSIS_20261024.md)

## 来源诊断：排序、门控和窗口提供什么线索

对固定选中模型的来源点分数，Task25 的 AP 相对 Task24 在种子 1019、2026 的两块均升，在 42 的两块均降；尤其 2026 的点 AP 提高，而两块平均事件门控 F1 下降。AP 描述阈值无关的点排序，门控 F1 描述固定高召回规则下的结果，两者不能互换。[来源分数诊断](../outputs/accuracy/microwave-task25-source-diagnostic-20261029-v1/报告.md)

按各模型已封存的 L/H 分解，12 个模型、种子和块组合中，峰值条件从已通过点分数条件的点中滤掉 6–130 个 FP，额外滤掉 TP 均为 0；这不意味着没有其他漏报，也不保证新家庭如此。Task24、25 的固定门控在同一来源点有大量共同 FP；两个模型及其各自阈值都不同，门控状态变化不能当作单因素因果。[固定门控诊断](../outputs/accuracy/microwave-fixed-gate-diagnostic-20261029-v1/报告.md)

共同 FP 的 core31 在六格全部观测，且每格 19.6%–73.1% 的完整 C127 窗口均有观测；外圈缺失不能解释全部共同 FP。每格共同 FP 中 93.6%–98.3% 的真实来源标签为 0，其余在 (0,200)，共同 FP 分组未知标签数量均为 0，未将未知标签填为关闭值；非零低于阈值的标签不足以解释大多数共同 FP，亦不能因此证明标签无误。共同 FP 总表中心功率及窗口变化的中位数明显高于共同 TN，中心功率与共同 TP 的数值范围相近。这提示来源总表形态可能存在辨别困难，但不能据此认定具体设备、物理原因或标签错误；重叠窗口和种子也不是独立事件。[来源窗口诊断](../outputs/accuracy/microwave-task25-source-window-diagnostic-20261029-v1/报告.md)

## 仍不确定，以及下一步

现有数据不能确定低 F1 由训练目标或权重、采样、容量、优化、输入上下文、标签质量、家庭分布或它们之间的交互中哪一项造成；也没有充分控制变量证明某项改动可改善未见家庭。House5 两个来源块已反复用于检查点、门控及候选比较，且 2/3 方案是在观察既有结果后提出；重复使用来源的结果是探索性证据，不是独立泛化验证。历史 House17 已多次用于开发，也不是独立最终测试。

最有区分力的下一步，是**先核查是否存在符合隔离规则、未用于模型或阈值选择的来源家庭或时段**，再预先固定现有模型、门控、评价支持及报告规则，比较错误背景和窗口形态是否在新支持上复现。这样能先区分当前错误模式是否局限于反复使用的来源；即使复现，也不能单凭总表判定具体设备或唯一原因。若没有合适来源数据，应先解决数据可用性，不能自动改用 House17 或最终 House8/9/20。

训练目标、困难负例、上下文或更多家庭仍可作为将来假设，但现有证据不足以承诺收益。任何后续实验应另行提出有限范围、选择规则和预算并取得相应授权；本轮已完成，不自动追加模型、搜索比例或追逐数值门槛。
